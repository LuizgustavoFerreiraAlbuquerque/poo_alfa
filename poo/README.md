# Sistema de Gestão Acadêmica Integrado (Python + TXT)

## Executar
No terminal, dentro desta pasta:

```bash
python main.py
```

O `main.py` reúne o CRUD de Alunos, Cursos, Professores e Disciplinas e o relatório integrado. Os registros são carregados dos TXT na inicialização e gravados automaticamente após cada inclusão, alteração ou exclusão.

Consulte `DOCUMENTACAO.md` para ver a relação entre cada RF01–RF18 e sua implementação.
